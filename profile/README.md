## 🧠 Overview

AIMP is a free desktop audio player for Windows that supports a wide range of audio formats and offers advanced playback features. It is designed for listeners who want precise audio control, playlist management, and built-in DSP processing without additional software. It is developed by Artem Izmaylov. The product family is positioned as a audio player toolset for Windows workflows.

AIMP works as a Windows utility on Windows 10 and Windows 11 and is installed from a single package.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🎵 Multi-Format Playback | Plays MP3, FLAC, AAC, OGG, WMA, APE, MPC, and dozens more formats natively. |
| 📋 Advanced Playlist Manager | Supports multiple simultaneous playlists with grouping, sorting, and auto-fill from folders. |
| 🎚️ 18-Band Equalizer | Built-in graphic equalizer with 18 bands and saveable presets for per-genre tuning. |
| 🔊 DSP Audio Effects | Applies reverb, chorus, pitch shift, tempo change, and speed adjustment in real time. |
| 🎙️ Audio Converter | Converts between supported formats using configurable bitrate, sample rate, and channel settings. |
| 📻 Internet Radio | Streams and records internet radio stations with ICY metadata and buffer size control. |
| 🏷️ Tag Editor | Reads and writes ID3v1, ID3v2, APEv2, Vorbis Comment, and iTunes tags across batch selections. |
| 🖥️ Global Hotkeys | Assigns system-wide keyboard shortcuts for playback control independent of window focus. |
| 🌐 Multi-Language UI | Ships with over 40 localizations; language packs are loaded from external translation files. |
| 🎨 Skin Support | Accepts custom visual skins that restyle the entire player window layout and color scheme. |
